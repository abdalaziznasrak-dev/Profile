# Radio Pharmacy Manager Profile Page

A modern, responsive profile page designed for radio pharmacy managers.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with gradient backgrounds and card-based layout
- **Information Sections**:
  - Personal Information (Employee ID, Department, License Number, Experience)
  - Contact Information (Email, Phone, Location)
  - Certifications & Specializations
  - Performance Metrics
  - Professional Summary

## How to Use

Simply open `index.html` in any modern web browser to view the profile page.

## Technology Stack

- HTML5
- CSS3 (with Flexbox and Grid)
- Responsive Design (Mobile-first approach)

## Customization

To customize the profile information, edit the content in `index.html`:
- Update personal information in the respective sections
- Modify the profile name and title in the header
- Add or remove certifications/badges as needed
- Update statistics and metrics

## Design Features

- Gradient backgrounds for visual appeal
- Card-based layout for organized information
- Smooth hover effects
- Professional color scheme (purple/blue gradient)
- Mobile-responsive design with breakpoints

- Chrome (latest)
- Firefox (latest)
